# Laravel - Mapeamento Objeto-Relacional

# 

# Projeto feito em Laravel com MySQL para demonstrar migrations e relacionamentos entre tabelas.

# 

# Relacionamentos

# 

# \- 1:1: Users → Profiles

# \- 1:N: Users → Posts

# \- N:M: Posts ↔ Tags, usando a tabela "post\_tag"

# 

# As tabelas foram criadas através das migrations com "php artisan migrate".

# 

# O arquivo "database\_schema.sql" contém o dump do banco.
